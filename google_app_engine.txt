>_

✅ STEP 8 — Create Simple App

Type these commands EXACTLY in terminal.


---

Create folder

mkdir myapp
cd myapp


---

Create Python file

Type:

nano main.py

Paste this:

from flask import Flask
app = Flask(__name__)

@app.route('/')
def hello():
    return 'Hello from Google App Engine'

if __name__ == '__main__':
    app.run(host='127.0.0.1', port=8080, debug=True)

Save:

Ctrl + O

Enter

Ctrl + X

✅ STEP 9 — Create app.yaml

nano app.yaml

Y

🎤 VIVA QUESTIONS & ANSWERS (IMPORTANT)

These are the MOST probable questions.


---

Q1. What is Google App Engine?

> Google App Engine is a Platform as a Service (PaaS) provided by Google Cloud to develop and host web applications.




---

Q2. What is PaaS?

> PaaS stands for Platform as a Service. It provides a platform to develop, run and deploy applications without managing servers.




---

Q3. What is cloud computing?

> Cloud computing means delivering computing services like storage, servers and software over the internet.




---

Q4. What is the difference between IaaS and PaaS?

IaaS	PaaS

Provides virtual hardware	Provides platform for application deployment
User manages OS	Provider manages OS
Example: EC2	Example: App Engine



---

Q5. Why is App Engine called serverless?

> Because developers do not manage physical servers manually. Google handles infrastructure automatically.




---

Q6. What language did you use?

> Python.




---

Q7. What is app.yaml?

> It is a configuration file used by App Engine to define runtime environment.




---

Q8. What is Flask?

> Flask is a lightweight Python web framework used to create web applications.




---

Q9. What command is used to deploy application?

gcloud app deploy


---

Q10. What command opens deployed application?

gcloud app browse


---

Q11. Advantages of App Engine?

> Easy deployment

Automatic scaling

No server management

Secure hosting





---

Q12. Disadvantages of App Engine?

> Internet dependency

Limited free resources

Vendor lock-in





---

Q13. What is runtime in App Engine?

> Runtime specifies programming language environment like Python, Java or Node.js.




---

Q14. What is Google Cloud SDK?

> It is a set of command-line tools used to manage Google Cloud services.
