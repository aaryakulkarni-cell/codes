Cell 1: Import libraries

import pandas as pd
import matplotlib.pyplot as plt

from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans

Cell 2: Load the dataset

df = pd.read_csv("/content/sales_data_sample.csv", encoding="latin1")

df.head()

Cell 3: Explore the dataset

print("Dataset Shape:", df.shape)

print(df.info())

print(df.isnull().sum())

Cell 4: Select features and preprocess the data

features = ["SALES", "QUANTITYORDERED", "PRICEEACH", "MSRP"]

X = df[features]

X = X.dropna()

X.head()

Cell 5: Normalize the data

scaler = StandardScaler()

X_scaled = scaler.fit_transform(X)

Cell 6: Apply the Elbow Method

wcss = []

for k in range(1, 11):
    kmeans = KMeans(n_clusters=k, random_state=42, n_init=10)
    kmeans.fit(X_scaled)

    wcss.append(kmeans.inertia_)

plt.plot(range(1, 11), wcss, marker="o")

plt.xlabel("Number of Clusters (K)")
plt.ylabel("WCSS")

plt.title("Elbow Method")

plt.show()

Cell 7: Apply K-Means clustering

optimal_k = 3

kmeans = KMeans(n_clusters=optimal_k, random_state=42, n_init=10)

y_kmeans = kmeans.fit_predict(X_scaled)

print("Cluster Labels:")
print(y_kmeans)

Here, 3 is just an example. Change it if your elbow graph suggests a different number.

Cell 8: Add cluster labels to the dataset

X["Cluster"] = y_kmeans

print(X.head(10))

Cell 9: Visualize the clusters

plt.scatter(X["SALES"], X["QUANTITYORDERED"], c=X["Cluster"])

plt.xlabel("Sales")
plt.ylabel("Quantity Ordered")

plt.title("K-Means Clustering")

plt.show()
