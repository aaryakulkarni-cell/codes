🧪 EXACT PRACTICAL EXECUTION (VERY IMPORTANT)

✅ STEP 1 — Login to Salesforce

Open: Salesforce Developer Signup

Login.


---

✅ STEP 2 — Open Setup

Top-right:

⚙ Setup

Click:

Setup


---

✅ STEP 3 — Create Custom Object

Search:

Object Manager

Open it.

Click:

Create → Custom Object


---

✅ STEP 4 — Fill Object Details

Fill:

Field	Value

Label	Student
Plural Label	Students
Object Name	Student


Click:

Save


---

✅ STEP 5 — Create Fields

Inside Student object:

Click:

Fields & Relationships

Then:

New

Create these fields.


---

Field 1

Type:

Text

Field Name:

Student_Name

Save.


---

Field 2

Type:

Number

Field Name:

Marks

Save.


---

✅ STEP 6 — Open Developer Console

Top-right profile/settings area.

Click:

Developer Console

New window opens.


---

✅ STEP 7 — Create Apex Class

In Developer Console:

Click:

File → New → Apex Class

Name:

StudentResult

Click OK.


---

✅ STEP 8 — Write Apex Code

Delete existing code and paste this EXACT code:

public class StudentResult {

    public static void checkResult(Integer marks) {

        if(marks >= 40) {
            System.debug('PASS');
        }
        else {
            System.debug('FAIL');
        }
    }
}


---

✅ STEP 9 — Save Code

Press:

Ctrl + S

OR File → Save.


---

✅ STEP 10 — Execute Program

Click:

Debug → Open Execute Anonymous Window

Paste:

StudentResult.checkResult(55);

Click:

Execute


---

✅ STEP 11 — Check Output

Bottom/logs area opens.

Search:

PASS

If PASS visible: 🎉 Practical successful.


---

📄 WHAT TO WRITE IN OUTPUT SECTION

> Apex program executed successfully and displayed PASS result.
