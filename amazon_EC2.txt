🧠 VERY IMPORTANT BASIC CONCEPTS (MEMORIZE)

☁️ What is Cloud Computing?

Using computer resources over internet instead of own hardware.


---

☁️ What is EC2?

EC2 is a service by Amazon Web Services that provides virtual servers on cloud.


---

☁️ What is an Instance?

A virtual computer/server running in cloud.


---

☁️ What is AMI?

AMI = operating system template like Ubuntu or Windows.


---

☁️ What is Security Group?

Firewall rules controlling network access.


---

☁️ What is Key Pair?

Used for secure SSH login into EC2 instance.
